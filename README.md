# Hypeframe

Cinematic anime moments discovery platform — Next.js 15 + React 19 + TypeScript.

## Run locally

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Checks

```bash
npm run typecheck
npm run build
```

## Features

- 12 editorially curated anime moment references
- Search and category filtering
- Spoiler protection (enabled by default)
- Browser-local hype votes and saved moments
- Native share or clipboard copy
- Responsive cinematic homepage

No anime footage or copyrighted stills are hosted.

## Deployment

Import this repository into Vercel, choose Next.js, and deploy. No environment variables are needed for the initial demo.

## Roadmap

Supabase Auth, database-backed voting, personal collections, moderation, licensed artwork and video embeds, and automated CI.

**Note:** Voting and saving currently persist only in the visitor's browser; these are not yet real community-wide features.
